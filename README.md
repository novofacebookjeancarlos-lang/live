# Lo-fi de Madrugada

Cena animada em 9:16 para abrir no navegador e capturar na live do TikTok. A ilustração fica fixa enquanto a piscada, as estrelas e as notas musicais seguem ciclos independentes.

Abra o site para ver a cena. **Escolher música** carrega uma faixa local e a repete automaticamente. A seleção vale para a aba aberta. Para definir uma faixa padrão para todos, coloque a URL do arquivo no atributo `data-track` do elemento `audio` em `index.html`. Use **Ocultar controles** para capturar a cena limpa e toque na cena para trazer os botões de volta.

Na Vercel, importe o repositório com a raiz como **Root Directory**. O `vercel.json` configura a publicação estática.
