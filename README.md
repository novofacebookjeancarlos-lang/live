# Lo-fi de Madrugada

Player vertical 9:16 para capturar no navegador e usar no TikTok LIVE Studio.

Use **Escolher vídeo** e **Escolher música** para abrir os arquivos do seu computador. Clique em **Iniciar** para tocar os dois. Cada arquivo recomeça ao chegar ao fim, mesmo que tenham durações diferentes. Quando uma faixa separada está selecionada, o áudio embutido do vídeo fica mudo.

Os arquivos locais ficam disponíveis na aba até ela ser fechada ou recarregada. Use **Ocultar controles** para capturar somente o vídeo. Clique sobre o vídeo para trazer os botões de volta.

Na Vercel, importe o repositório com a raiz como **Root Directory**. O arquivo `vercel.json` configura a publicação estática.
